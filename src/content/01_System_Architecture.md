# System Architecture

The master technical spec for v1.0, detailing the hybrid architecture, the 5 core UI views (Nexus, Projects, Vessels, Vault, Principles), and data schemas.

## Core Views
- **Nexus**: The central hub.
- **Projects**: Where work happens.
- **Vessels**: AI agents.
- **Vault**: Stored knowledge.
- **Principles**: Core rules.
